# 2. Modifications d'architecture

> Diagramme d'architecture (C4) du modèle : systèmes et intégrations nouveaux ou modifiés signalés dans la légende. Insérez ![légende](diagram:ID).

## 2.2 Diagramme de séquence
> Diagramme(s) de séquence décrivant la communication entre les systèmes. Sous chacun, une brève description des étapes.
