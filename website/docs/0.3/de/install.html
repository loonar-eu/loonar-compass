Installationsanleitung

2. Voraussetzungen

Notwendige Bedingungen. Unterstützt wird die Anwendung nur, wenn alle drei erfüllt sind:
  1. Das Modell liegt in einer PostgreSQL-Datenbank. Modelle in Dateien (.qea, .qeax, .eap, .eapx, .feap) sowie in anderen Datenbanken werden nicht unterstützt.
  2. Im Modell ist die Benutzersicherheit aktiviert (in Enterprise Architect: Settings → Security → Enable Security), im Modus „Require User Lock to Edit“. Die Anwendung meldet sich als bestimmter Benutzer am Modell an und sperrt beim Speichern die geänderten Objekte. Ohne Benutzersicherheit setzt sie keine Sperren; diese Konfiguration wird nicht unterstützt.
  3. Im Modell gibt es ein Benutzerkonto für den Assistenten (Settings → Security → Users), mit Passwort und Bearbeitungsrechten. Der Kontoname ist beliebig, zum Beispiel claude oder assistent, aber das Konto muss existieren. Anmeldename und Passwort geben Sie in den Einstellungen der Anwendung ein.

3. Installation

Starten Sie die Datei LoonarCompass-Setup-0.3.exe. Standardmäßig installieren Sie die Anwendung nur für sich selbst, ohne Administratorrechte; Windows fragt nur dann nach Administratorrechten, wenn Sie die Installation für alle Benutzer des Computers wählen. Der Installationsassistent führt Sie mit den Schaltflächen Weiter und Zurück durch die einzelnen Schritte.

Warnung von Windows SmartScreen. Das Installationsprogramm ist noch nicht digital signiert, daher kann Windows beim ersten Start die Meldung „Der Computer wurde durch Windows geschützt“ anzeigen. Klicken Sie auf Weitere Informationen und dann auf Trotzdem ausführen. Ist auf dem Computer die Intelligente App-Steuerung (Smart App Control) aktiviert, blockiert Windows nicht signierte Anwendungen ohne Möglichkeit, sie zu starten; warten Sie in diesem Fall auf die signierte Version. Laden Sie das Installationsprogramm nur von loonar.eu oder aus den Releases des Projekts auf GitHub herunter.
  1. Sprache. Zu Beginn fragt das Installationsprogramm nach der Sprache: Polnisch, Englisch, Deutsch oder Französisch. Bei einer Neuinstallation ist Englisch ausgewählt, bei einer Aktualisierung die in Ihren Einstellungen gespeicherte Sprache. Die gewählte Sprache gilt für den Installationsassistenten, die Anwendung, die Antworten des Assistenten und die Standard-Dokumentvorlagen; später ändern Sie sie in den Einstellungen (Kapitel 5).
  2. Begrüßung. Die Voraussetzungen und eine Liste der Dinge, die Sie vor der Installation bereithalten sollten.
  3. Neu in Version 0.3. Bei einer Aktualisierung: die Änderungen seit der installierten Version. Bei einer Neuinstallation: die wichtigsten Änderungen der aktuellen Version.
  4. Lizenzvereinbarung. Wählen Sie „Ich akzeptiere die Bedingungen der Lizenzvereinbarung“.
  5. Zielordner. Die Installationsart (siehe unten), der Installationsordner und die Verknüpfungen: Startmenü (Anwendung, Benutzerhandbuch, Deinstallation) und Desktop.
  6. Konfiguration. Sie können die Daten sofort eingeben („Ich gebe die Daten jetzt ein“) oder „Ich konfiguriere später in der Anwendung“ wählen. Die Seite enthält den Claude-API-Schlüssel (mit einem Hinweis, was an Anthropic gesendet wird), die Modelldatenbank (Server, Port, Datenbankname, Datenbankkonto, Datenbankpasswort), Enterprise Architect (Pfad zu EA.exe, den Sie mit der Schaltfläche … in einem Dateiauswahlfenster wählen, EA-Benutzerkonto und Passwort des EA-Kontos) sowie den Freigabemodus.
  7. Bereit zur Installation. Eine Zusammenfassung; mit Installieren beginnt die Installation. Der Fortschrittsbalken zeigt den Prozentsatz und den aktuellen Schritt.
  8. Installation abgeschlossen. Ist „Loonar Compass starten“ ausgewählt, öffnet sich die Anwendung nach einem Klick auf Fertigstellen.

Installationsart

Auf der Seite „Zielordner“ wählen Sie, für wen Sie die Anwendung installieren:

  • „Nur für mich (empfohlen, ohne Administratorrechte)“: Die Anwendung wird in %LOCALAPPDATA%\Programs\Loonar Compass installiert und steht nur Ihrem Windows-Konto zur Verfügung.
  • „Für alle Benutzer dieses Computers (erfordert Administratorrechte)“: Die Anwendung wird in %ProgramFiles%\Loonar Compass installiert. Nach einem Klick auf Installieren fragt Windows nach Administratorrechten; werden sie nicht erteilt, wird nichts installiert. Der Ordner muss im Ordner „Programme“ liegen, in dem nur Administratoren Dateien ändern können.

Unabhängig von der Installationsart werden Einstellungen und Passwörter immer für den Benutzer gespeichert, der den Installationsassistenten gestartet hat: im Benutzerprofil (%APPDATA%\Loonar Compass) und in seiner Windows-Anmeldeinformationsverwaltung, auch wenn eine andere Person die Administratorrechte bestätigt. Bei einer Installation für alle Benutzer hat jeder Benutzer eigene Einstellungen, Unterhaltungen und Passwörter.

Taskleiste. Windows 11 erlaubt Installationsprogrammen nicht, Programme an die Taskleiste anzuheften. Starten Sie die Anwendung, klicken Sie mit der rechten Maustaste auf ihr Symbol in der Taskleiste und wählen Sie „An Taskleiste anheften“.

Aktualisierung von einer früheren Version

Loonar Compass ist der neue Name von Loonar EA Assistant: Einstellungen, Unterhaltungen, Gedächtnis, Vorlagen und Passwörter der früheren Version übernimmt die Anwendung beim ersten Start automatisch.

  • Eine frühere Version, die nur für Sie installiert war, entfernt das Setup während der Installation (Programmdateien, Verknüpfungen und Eintrag in den Windows-Einstellungen); Ihre Daten bleiben erhalten.
  • Ist die frühere Version für alle Benutzer installiert (zum Beispiel unter Program Files), zeigt die Seite „Bereit zur Installation“ einen Hinweis mit der Schaltfläche Alte Version entfernen (Administratorrechte). Sie können sie auch später unter Einstellungen → Apps entfernen; Ihre Einstellungen und Unterhaltungen bleiben in beiden Fällen erhalten.
  • Auf der ersten Seite wählt das Setup die in Ihren Einstellungen gespeicherte Sprache vor (Einstellungen ohne gespeicherte Sprache stammen aus den rein polnischen Versionen 0.1 und 0.2 und bedeuten Polnisch), ohne Einstellungen Englisch. Prüfen Sie diese Auswahl, bevor Sie auf Weiter klicken.
  • Ein Sprachwechsel im Setup übersetzt weder das Gedächtnis noch die Vorlagen. Wenn Sie diese in die neue Sprache übertragen möchten, behalten Sie im Setup die bisherige Sprache bei und ändern Sie sie nach der Installation auf Karte 4 der Einstellungen (Kapitel 5).
  • Ein Datenbankpasswort, das ältere Versionen in der Einstellungsdatei gespeichert haben, wird in die Windows-Anmeldeinformationsverwaltung übertragen, und Dateien und Ordner mit polnischen Namen im Datenordner erhalten englische Namen (zum Beispiel audit_log.jsonl und templates).

17. Aktualisierung und Deinstallation

Aktualisierung. Schließen Sie die Anwendung und starten Sie das Installationsprogramm der neueren Version. Der Installationsassistent zeigt die Seite „Neu in Version …“ mit den Änderungen seit der installierten Version, übernimmt die Installationsart und den Ordner der bestehenden Installation und behält Ihre Einstellungen, den Unterhaltungsverlauf, die Anhänge, das Gedächtnis, die Vorlagen und das Änderungsprotokoll. Zur Aktualisierung von einer Version vor 0.3 siehe Kapitel 3.

Schließen der Anwendung. Das Schließen des Fensters schließt auch die von der Anwendung im Hintergrund gestartete Enterprise-Architect-Sitzung, sodass die EA-Lizenz sofort freigegeben wird.

Deinstallation. Schließen Sie die Anwendung. Verwenden Sie die Verknüpfung „Loonar Compass deinstallieren“ im Startmenü oder den Eintrag „Loonar Compass“ unter Einstellungen → Apps → Installierte Apps. Bei einer Installation für alle Benutzer fragt Windows nach Administratorrechten. Das Deinstallationsprogramm entfernt die Programmdateien, die Verknüpfungen und den Systemeintrag und zeigt den Fortschritt in einem Balken an. Ihre Daten bleiben erhalten, es sei denn, Sie wählen:

  • „Einstellungen, Unterhaltungen, Anhänge, Gedächtnis des Assistenten, Dokumentvorlagen und Änderungsprotokoll entfernen“: Dabei wird der gesamte Benutzerdatenordner %APPDATA%\Loonar Compass gelöscht,
  • „API-Schlüssel, Passwörter und Tokens aus der Anmeldeinformationsverwaltung entfernen“: alle Geheimnisse der Anwendung, auch das Confluence-Token und das Datenbankpasswort.

Entfernt werden nur die Daten des Benutzers, der die Deinstallation gestartet hat; die Daten anderer Benutzer bleiben in deren Profilen.
