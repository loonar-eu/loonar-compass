Instrukcja instalacji

2. Wymagania

Warunki konieczne. Obsługiwana konfiguracja wymaga spełnienia następujących warunków:
  1. Model jest plikiem projektu EA .qea lub .qeax albo jest w bazie danych PostgreSQL. Starsze formaty plików (.eap, .eapx, .feap) oraz inne bazy nie są obsługiwane; plik .eap/.eapx Enterprise Architect przekonwertuje do .qea transferem projektu (Settings → Model → Transfer → Full Project Transfer).
  2. Model w bazie ma włączone zabezpieczenia użytkowników (w Enterprise Architect: Settings → Security → Enable Security), w trybie „Require User Lock to Edit”. W pliku modelu zabezpieczenia są opcjonalne: bez nich asystent nie potrzebuje konta EA. Aplikacja loguje się do modelu na konto asystenta i na czas zapisu zakłada blokady. Gdy zabezpieczenia są wyłączone, blokady są pomijane, a taka konfiguracja nie jest obsługiwana.
  3. W modelu z włączonymi zabezpieczeniami istnieje konto użytkownika dla asystenta (Settings → Security → Users), z hasłem i z uprawnieniami do edycji. Nazwa konta jest dowolna, na przykład claude albo asystent. Login i hasło tego konta podajesz w ustawieniach aplikacji.

3. Instalacja

Uruchom plik LoonarCompass-Setup-0.6.exe. Kreator prowadzi przez kolejne strony przyciskami Dalej i Wstecz. Uprawnień administratora nie potrzebujesz, chyba że instalujesz aplikację dla wszystkich użytkowników komputera.

Ostrzeżenie Windows SmartScreen. Instalator nie jest jeszcze podpisany cyfrowo, dlatego przy pierwszym uruchomieniu Windows może pokazać komunikat „System Windows ochronił ten komputer”. Kliknij Więcej informacji, a potem Uruchom mimo to. Gdy w systemie jest włączona Inteligentna kontrola aplikacji (Smart App Control), Windows blokuje niepodpisane aplikacje bez możliwości ich uruchomienia: poczekaj wtedy na wersję podpisaną. Instalator pobieraj tylko z loonar.eu albo z wydań projektu na GitHubie.
  1. Język. Polski, angielski, niemiecki albo francuski. Przy nowej instalacji zaznaczony jest angielski, a przy aktualizacji język zapisany w Twoich ustawieniach. Wybrany język dotyczy kreatora, aplikacji, odpowiedzi asystenta i domyślnych szablonów dokumentów; później zmienisz go w ustawieniach (rozdział 5).
  2. Powitanie. Warunki konieczne i lista rzeczy, które warto przygotować przed instalacją.
  3. Co nowego. Przy aktualizacji: zmiany od zainstalowanej wersji. Przy nowej instalacji: najważniejsze zmiany w bieżącej wersji.
  4. Umowa licencyjna. Zaznacz „Akceptuję warunki umowy licencyjnej”.
  5. Folder docelowy. Rodzaj instalacji (opisany niżej), folder programu i skróty: w menu Start (aplikacja, instrukcja użytkownika, odinstalowanie) i na pulpicie.
  6. Konfiguracja. Wybierz „Podam dane teraz” albo „Skonfiguruję później w aplikacji (widok »Ustawienia«)”. Od razu możesz podać klucz API Claude (pod polem jest informacja, co trafia do Anthropic), model (bazę PostgreSQL: serwer, port, nazwa bazy, konto i hasło do bazy, albo plik EA: ścieżka do pliku .qea/.qeax, którą wybierzesz przyciskiem …), ścieżkę do EA.exe (przycisk … otwiera wybór pliku), konto i hasło użytkownika EA oraz tryb zatwierdzania zmian. Puste pole hasła lub klucza zostawia wartość zapisaną wcześniej.
  7. Gotowy do instalacji. Podsumowanie wyborów. Kliknij Instaluj; pasek postępu pokazuje procent i bieżący krok.
  8. Zakończenie. Zaznaczona opcja „Uruchom Loonar Compass” otwiera aplikację po kliknięciu Zakończ.

Rodzaj instalacji

Na stronie „Folder docelowy” wybierasz, dla kogo instalujesz aplikację:

  • „Tylko dla mnie (zalecane, bez uprawnień administratora)”: program trafia do folderu %LOCALAPPDATA%\Programs\Loonar Compass. Windows nie prosi o uprawnienia administratora.
  • „Dla wszystkich użytkowników tego komputera (wymaga uprawnień administratora)”: program trafia do folderu %ProgramFiles%\Loonar Compass, w którym pliki mogą zmieniać tylko administratorzy. Windows prosi o uprawnienia administratora dopiero po kliknięciu Instaluj. Jeśli ich nie przyznasz, nic nie zostanie zainstalowane.

Ustawienia i hasła zawsze trafiają do profilu użytkownika, który uruchomił kreator, także wtedy, gdy uprawnienia administratora potwierdza inna osoba. Przy instalacji dla wszystkich użytkowników każdy z nich ma własne ustawienia, rozmowy i hasła.

Pasek zadań. Windows 11 nie pozwala instalatorom przypinać programów do paska zadań. Uruchom aplikację, kliknij jej ikonę na pasku prawym przyciskiem myszy i wybierz „Przypnij do paska zadań”.

Aktualizacja z wcześniejszej wersji

Wcześniejsze wersje aplikacji nosiły nazwę Loonar EA Assistant: Loonar Compass automatycznie przejmuje ich ustawienia, rozmowy, pamięć asystenta, szablony i hasła.

  • Wcześniejsza wersja zainstalowana tylko dla Ciebie jest usuwana podczas instalacji (pliki programu, skróty i wpis w ustawieniach Windows); Twoje dane zostają.
  • Wcześniejszą wersję zainstalowaną dla wszystkich użytkowników kreator pokazuje na stronie „Gotowy do instalacji”. Usuniesz ją przyciskiem Usuń starą wersję (uprawnienia administratora) albo później w ustawieniach Windows (Aplikacje). Twoje ustawienia i rozmowy zostają.
  • Na pierwszej stronie kreator zaznacza język zapisany w Twoich ustawieniach (ustawienia bez zapisanego języka oznaczają polski), a gdy ustawień nie ma, angielski. Sprawdź ten wybór, zanim klikniesz Dalej.
  • Zmiana języka w kreatorze nie tłumaczy pamięci asystenta ani szablonów. Jeśli chcesz je przenieść na nowy język, zostaw w kreatorze dotychczasowy język, a po instalacji zmień go w karcie 4 ustawień (rozdział 5).
  • Hasło do bazy, które starsze wersje trzymały w pliku ustawień, trafia do Menedżera poświadczeń Windows, a pliki z polskimi nazwami w folderze danych dostają nazwy angielskie (na przykład audit_log.jsonl i templates).

19. Aktualizacja i odinstalowanie

Aktualizacja. Zamknij aplikację i uruchom instalator nowszej wersji. Kreator pokaże stronę „Co nowego” ze zmianami od zainstalowanej wersji, zaproponuje ten sam rodzaj instalacji i folder oraz zachowa Twoje ustawienia, hasła, historię rozmów, załączniki, pamięć, szablony i dziennik zmian. Aktualizację z wersji o dawnej nazwie opisuje rozdział 3.

Zamykanie aplikacji. Zamknięcie okna zamyka też sesję Enterprise Architect uruchomioną w tle przez aplikację, więc licencja EA jest od razu zwalniana.

Odinstalowanie. Zamknij aplikację. Użyj skrótu „Odinstaluj Loonar Compass” w menu Start albo pozycji „Loonar Compass” w ustawieniach Windows (Aplikacje → Zainstalowane aplikacje). Przy instalacji dla wszystkich użytkowników Windows poprosi o uprawnienia administratora. Program odinstalowujący usuwa pliki programu, skróty i wpis w systemie, pokazując postęp na pasku. Twoje dane zostają na komputerze, chyba że zaznaczysz:

  • „Usuń ustawienia, rozmowy, załączniki, pamięć asystenta, szablony dokumentów i dziennik zmian”: usuwa cały folder %APPDATA%\Loonar Compass,
  • „Usuń klucz API, hasła i tokeny z Menedżera poświadczeń”: usuwa wszystkie sekrety aplikacji, także hasło do bazy i token Confluence.

Usuwane są tylko dane użytkownika, który uruchomił odinstalowanie; dane innych użytkowników zostają w ich profilach.
