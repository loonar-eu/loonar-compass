Politique de confidentialité

Dernière mise à jour : 17 octobre 2026

1. Responsable du traitement

Mariusz Głowacki, entrepreneur individuel exerçant sous la dénomination Loonar Mariusz Głowacki, ul. Gombrowicza 12, 73-110 Stargard, Pologne, NIP (numéro fiscal) 8542139307, REGON 320090308. Contact : mariusz@loonar.eu.

2. Hébergement de ce site (GitHub Pages)

Le site est hébergé sur GitHub Pages, un service de GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, États-Unis. Lorsque vous ouvrez une page, votre navigateur se connecte aux serveurs de GitHub, qui reçoivent votre adresse IP et les données techniques habituelles de la requête (adresse demandée, heure, navigateur, page de provenance). GitHub traite votre adresse IP pour fournir le site et, selon la documentation de GitHub Pages, l’enregistre dans ses journaux à des fins de sécurité ; nous n’avons pas accès à ces journaux. Nous utilisons GitHub Pages sur la base de notre intérêt légitime à fournir le site de manière sûre et fiable (art. 6, par. 1, point f du RGPD).

GitHub traite des données personnelles notamment aux États-Unis. Pour les transferts depuis l’Union européenne, il s’appuie sur le cadre de protection des données UE–États-Unis (EU-U.S. Data Privacy Framework), auquel il participe, et sur les clauses contractuelles types de la Commission européenne. Détails : déclaration de confidentialité de GitHub (GitHub General Privacy Statement).

3. Statistiques de visite (GoatCounter)

Pour savoir combien de personnes visitent le site et téléchargent l’application, nous utilisons GoatCounter (goatcounter.com, exploité par Martin Tournoij, Irlande ; données stockées dans l’UE, sur des serveurs Hetzner en Finlande et en Allemagne). Le compteur fait partie du code de ce site : aucun script externe n’est chargé, et aucun cookie ni identifiant similaire n’est utilisé.

À l’ouverture d’une page, votre navigateur envoie à GoatCounter l’adresse et le titre de la page, la page de provenance et la largeur de l’écran ; lors d’un clic sur le bouton de téléchargement ou sur un lien vers GitHub, suppi.pl, la politique de confidentialité ou les mentions légales, il envoie le nom de cet événement et la page sur laquelle vous avez cliqué. À partir de la requête elle-même, GoatCounter détermine le navigateur et le système d’exploitation, la langue et le pays (d’après l’adresse IP). Il ne conserve que des décomptes agrégés de ces données – ni votre adresse IP, ni l’identification complète du navigateur (User-Agent), ni aucun identifiant vous concernant. Pour ne pas compter deux fois une même visite, il garde la combinaison de l’adresse IP et de l’identification du navigateur uniquement en mémoire, pendant 8 heures au plus. Sans JavaScript, rien n’est compté. Base juridique : notre intérêt légitime à disposer de statistiques anonymes sur l’utilisation du site (art. 6, par. 1, point f du RGPD). En savoir plus : politique de confidentialité de GoatCounter.

4. Données enregistrées dans votre navigateur

Si vous choisissez une langue (ou fermez la suggestion de langue), votre navigateur mémorise ce choix dans son stockage local (localStorage, clé loonar-lang) ; si vous désactivez le comptage, il le mémorise aussi (clé loonar-nocount). Ces informations ne nous sont pas transmises ; vous pouvez les effacer dans les paramètres du navigateur.

5. Téléchargements et liens vers d’autres services

Le programme d’installation se télécharge depuis GitHub Releases (github.com), et les liens vers le code source mènent aussi à GitHub ; GitHub, Inc. y traite vos données selon sa propre déclaration de confidentialité. Le bouton de la section « Soutenir le projet » mène à suppi.pl, un service qui gère les paiements selon ses propres conditions et sa propre politique de confidentialité, et le lien de la section « À propos de moi » mène à LinkedIn. Si vous soutenez le projet, nous ne recevons que les données que suppi.pl transmet au bénéficiaire du soutien, et nous les utilisons pour enregistrer le paiement et, dans la mesure exigée par la loi, à des fins comptables et fiscales (art. 6, par. 1, point c du RGPD).

6. E-mails et signalements de bugs

Lorsque vous nous écrivez ou envoyez un signalement depuis l’application, nous traitons votre adresse e-mail, votre nom s’il est indiqué, le message, les captures d’écran jointes et, si vous laissez l’option activée, des informations techniques (version de l’application, version de Windows, modèle d’IA, mode de validation, dernier message). Nous les utilisons pour vous répondre et améliorer l’application (art. 6, par. 1, point f du RGPD). Nous les conservons jusqu’à la clôture du dossier, puis jusqu’à 2 ans. Merci de ne pas joindre de données d’autres personnes ni d’informations confidentielles.

7. Informations sur les nouvelles versions

Si vous vous inscrivez dans l’application (Paramètres → Nouvelles versions), nous utilisons votre adresse e-mail uniquement pour vous informer des nouvelles versions, sur la base de votre consentement (art. 6, par. 1, point a du RGPD), jusqu’à son retrait – en décochant l’option dans l’application ou par e-mail. Le retrait n’affecte pas les envois antérieurs. Nous conservons les messages d’inscription et de désinscription comme preuve pendant 3 ans au plus (art. 6, par. 1, point f du RGPD).

8. L’application

Loonar Compass ne nous envoie aucune donnée (aucune télémétrie). Les paramètres, conversations, la mémoire et les modèles restent sur votre ordinateur. Pour répondre, l’application envoie la conversation, les pièces jointes, les notes mémorisées, les modèles de document utilisés et les extraits du modèle nécessaires (y compris les images de diagrammes) directement à Anthropic (API Claude), avec votre clé API et en vertu de votre contrat avec Anthropic ; pour ce traitement, nous ne sommes pas responsable du traitement. Les pages Confluence sont envoyées uniquement au serveur que vous indiquez.

9. Destinataires

Les destinataires des données sont nos prestataires : GitHub, Inc. (hébergement du site et téléchargement du programme d’installation), GoatCounter (statistiques de visite) et notre prestataire de messagerie. Si des données sont traitées hors de l’Espace économique européen (pour GitHub, aux États-Unis), c’est sur la base d’une décision d’adéquation de la Commission européenne (EU-U.S. Data Privacy Framework) ou des clauses contractuelles types de la Commission européenne.

10. Vos droits

Vous disposez d’un droit d’accès, de rectification, d’effacement, de limitation du traitement, de portabilité, d’opposition et du droit de retirer votre consentement à tout moment. Les statistiques de visite ne contiennent aucune donnée permettant de vous identifier ; nous ne pouvons donc pas vous les attribuer (art. 11 du RGPD). Vous pouvez introduire une réclamation auprès de l’autorité polonaise de protection des données (Prezes Urzędu Ochrony Danych Osobowych, ul. Stawki 2, 00-193 Varsovie) ou de l’autorité de votre pays de résidence (en France : la CNIL). La fourniture des données est facultative. Nous ne procédons à aucune prise de décision automatisée ni à aucun profilage.
