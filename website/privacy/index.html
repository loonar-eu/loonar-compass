Privacy policy

Last updated: 27 October 2026

1. Controller

Mariusz Głowacki, running the business Loonar Mariusz Głowacki, ul. Gombrowicza 12, 73-110 Stargard, Poland, NIP (tax ID) 8542139307, REGON 320090308. Contact: mariusz@loonar.eu.

2. Hosting of this website (GitHub Pages)

The website is hosted on GitHub Pages, a service of GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. When you open a page, your browser connects to GitHub’s servers, which receive your IP address and the usual technical data of the request (requested address, time, browser, referring page). GitHub processes your IP address to deliver the website and, according to the GitHub Pages documentation, logs it for security purposes; we have no access to these logs. We use GitHub Pages on the basis of our legitimate interest in delivering the website securely and reliably (Art. 6(1)(f) GDPR).

GitHub processes personal data in the USA, among other places. For transfers from the European Union, it relies on the EU-U.S. Data Privacy Framework, in which it participates, and on the European Commission’s standard contractual clauses. Details: GitHub General Privacy Statement.

3. Visit statistics (GoatCounter)

To know how many people visit the website and download the application, we use GoatCounter (goatcounter.com, run by Martin Tournoij, Ireland; data stored in the EU, on Hetzner servers in Finland and Germany). The counter is part of this website’s own code: no external script is loaded, and no cookies or similar identifiers are used.

When you open a page, your browser sends GoatCounter the page address and title, the referring page and the screen width; when you click the download button or a link to GitHub, suppi.pl, the privacy policy or the legal notice, it sends the name of that event and the page on which you clicked. From the request itself, GoatCounter determines the browser and operating system, the language and the country (from the IP address). It stores only aggregate counts of these data – not your IP address, not the full browser identification (User-Agent) and no identifier of you. To avoid counting a repeated visit twice, it keeps the combination of IP address and browser identification in memory only, for at most 8 hours. Without JavaScript, nothing is counted. Legal basis: our legitimate interest in anonymous statistics on the use of the website (Art. 6(1)(f) GDPR). More: GoatCounter privacy policy.

4. Data stored in your browser

If you choose a language (or close the language suggestion), your browser remembers the choice in its local storage (localStorage, key loonar-lang); if you switch the counting off, it remembers that too (key loonar-nocount). These entries never reach us, and you can delete them in your browser settings.

5. Downloads and links to other services

You download the installer from GitHub Releases (github.com), and the links to the source code also lead to GitHub; there, GitHub, Inc. processes your data under its own privacy statement. The button in the “Support the project” section leads to suppi.pl, a service that handles payments under its own terms and privacy policy, and the link in the “About me” section leads to LinkedIn. If you support the project, we receive only the data that suppi.pl passes on to the recipient of the support, and we use it to record the payment and, where the law requires it, for accounting and tax purposes (Art. 6(1)(c) GDPR).

6. E-mails and bug reports

When you write to us or send a bug report from the application, we process your e-mail address, your name if given, the message, attached screenshots and, if you leave the option on, technical information (application version, Windows version, AI model, approval mode, number of steps, installation id). We use them to answer and to improve the application (Art. 6(1)(f) GDPR). We keep them until the matter is closed and then for up to 2 years. Please do not include other people’s data or confidential information.

A report sent from the application as a public issue on GitHub is published in the repository github.com/loonar-eu/loonar-compass: its title, your description and, if you leave the option on, the technical information are visible to everybody. Screenshots, the reported answer (your question, the answer and its steps) and your e-mail address are stored in a private repository that only we can read. A report sent by e-mail is not published.

7. News about new versions

If you sign up in the application (Settings → New releases), we use your e-mail address only to send news about new versions, based on your consent (Art. 6(1)(a) GDPR), until you withdraw it – by unticking the option in the application or by e-mail. Withdrawal does not affect messages sent before. We keep the sign-up and withdrawal messages as proof for up to 3 years (Art. 6(1)(f) GDPR).

8. The application

Usage statistics. Unless you switch them off, Loonar Compass sends us anonymous usage statistics. At each start it sends a random installation id (created by the application on your computer, not derived from the computer or from you), the application version, the Windows version, the interface language and the day. Every hour it sends a summary of the day so far: the kinds of tasks done (for example a diagram, a document, a change of the model, a question about the model) and how they ended, how often each function of the assistant was used and how often it failed, ratings of answers (👍/👎 with the reason chosen), what the assistant could not do, approvals asked, accepted and rejected, views opened, tokens used and the kind of setup (model source, AI provider and model family, approval mode, whether Jira, Confluence, the team hub, MCP servers and event agents are set up). They never contain the content of conversations, names or ids from the model, file paths, server addresses, error messages or user names. The installation id lets us count active installations and see whether the application is used again; we cannot link it to a person. The data is received and stored by our service on Cloudflare (Cloudflare, Inc., Cloudflare Workers and D1), which does not store IP addresses; only we can read it, and only summaries over all installations together are published. We keep it for 13 months. We use it to learn which functions are used, where errors occur and what to improve first (Art. 6(1)(f) GDPR). The application shows a notice at the first start and shows everything it sent in the last 30 days in the “Usage statistics” view; there you can switch the statistics off at any time (days not sent yet are then deleted) or create a new installation id. Organisations can switch them off with the environment variable LOONAR_TELEMETRY=0, a registry policy or the policy of the team hub.

Settings, conversations, memory and templates stay on your computer. To answer, the application sends the conversation, attachments, remembered notes, the templates in use and the model excerpts it needs (including diagram images) directly to the AI provider chosen in the settings - Anthropic (Claude API) or OpenAI (OpenAI API) - under your API key and your agreement with that provider, each under its own terms and privacy policy; for that processing we are not the controller. Confluence pages go only to the server you configure.

Every hour the application asks GitHub (api.github.com, GitHub, Inc.) for the number of the latest release, to tell you about a new version. This is a plain request: it contains no identifier of the installation and no data from your models; GitHub sees your IP address, as with any connection. Nothing is downloaded or installed by itself. You can switch the check off in the application (Settings → New releases (newsletter) → “Check every hour…”), and a team hub can switch it off for everybody.

9. Recipients

The recipients of data are our service providers: GitHub, Inc. (website hosting, the installer download and bug reports), Cloudflare, Inc. (the service that receives and stores usage statistics and receives bug reports from the application), GoatCounter (visit statistics) and our e-mail provider. Where data is processed outside the European Economic Area (for GitHub and Cloudflare, in the USA), this happens on the basis of an adequacy decision of the European Commission (EU-U.S. Data Privacy Framework) or of the European Commission’s standard contractual clauses.

10. Your rights

You have the right to access, rectify and erase your data, to restrict processing, to data portability, to object and to withdraw consent at any time. The visit statistics contain no data that identifies you, so we cannot attribute them to you (Art. 11 GDPR). You can lodge a complaint with the President of the Personal Data Protection Office (UODO), ul. Stawki 2, 00-193 Warsaw, Poland. Providing data is voluntary. We do not use automated decision-making or profiling.
