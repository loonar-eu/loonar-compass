# Security policy

## Reporting a vulnerability

Please report security problems privately by e-mail to **mariusz@loonar.eu** with the subject
"Security: Loonar Compass". Do not open a public GitHub issue for a vulnerability.

Include, if you can:

- the version (Settings → About, or the installer file name),
- what an attacker can do and the steps to reproduce it,
- whether the issue needs a malicious attachment, document, model content or a local account.

You will get a reply within 5 working days. Confirmed issues are fixed in the next release and
described in the changelog; reporters are credited unless they prefer otherwise.

## Supported versions

Only the latest released version receives security fixes.

## Scope

In scope: the Loonar Compass application and its installer, as published on
[loonar.eu](https://loonar.eu) and in this repository's releases.

Out of scope: Sparx Enterprise Architect, the Anthropic Claude API, Atlassian Confluence,
PostgreSQL and Microsoft Windows themselves - please report those to their vendors.
